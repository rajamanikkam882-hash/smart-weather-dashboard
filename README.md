# Smart Weather & Travel Dashboard

## Project Description

A responsive web application that provides weather information
and travel suggestions for different cities.

## Features

- City Search
- Current Weather
- Temperature
- Weather Condition
- Dynamic Weather Icons
- Humidity
- Wind Speed
- 5-Day Weather Forecast
- Travel Suggestions
- Invalid City Error Handling
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Fetch API
- Async/Await
- DOM Manipulation
- Open-Meteo API

## Project Structure

smart-weather-dashboard/
│
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Open the project in VS Code.
2. Open `index.html`.
3. Use Live Server.
4. Enter a city name.
5. Click Search.
